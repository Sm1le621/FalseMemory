# Welcome2DScript

## 1. Название и назначение

**Исходный файл:** F:/LLM/UUU/Miri/FalseMemory/Assets/Welcome/Welcome2DScript.cs.

Служебный ScriptableObject шаблона Unity 2D; не игровая система FalseMemory.

## 2. Как работает

Класс Unity.U2D.Welcome с CreateAssetMenu. Метод открывает сайт только при явном вызове, не в каждом кадре.

## 3. Методы и функции

`Open2DLandingPage()` — статический метод без параметров/результата, вызывает Application.OpenURL для https://unity.com/features/2d. Автоматических Unity callbacks нет.

## 4. Переменные и параметры Inspector

Игровых параметров и редактируемых полей Inspector нет.

## 5. Связи с другими системами

Зависит только от UnityEngine.Application; не связан с боем, игроком и здоровьем.

## 6. Пример работы

Пользователь вызывает ссылку стартового шаблона → открывается страница Unity 2D.

## 7. Возможные проблемы и проверки

Описана только прочитанная реализация; браузер в этой задаче не открывался.
