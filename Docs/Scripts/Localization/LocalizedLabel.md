# LocalizedLabel

## 1. Название и назначение

**Исходный файл:** `Assets/Scripts/Localization/LocalizedLabel.cs`.

Связывает статическую TMP-подпись с одним ключом `GameText` и обновляет её при смене языка. Используется преимущественно объектами, сохранёнными в сценах.

## 2. Как работает

Компонент добавляется в сцене на тот же GameObject, что и `TMP_Text`. `Awake` кеширует текст, `OnEnable` подписывается на `GameText.LanguageChanged` и сразу применяет ключ, `OnDisable` отписывается. Пустой ключ оставляет текущий текст без изменений.

## 3. Методы и функции

- `Awake()` — кеширует `TMP_Text`.
- `OnEnable()` — подписка на `GameText.LanguageChanged`, затем `Refresh()`.
- `OnDisable()` — отписка.
- `Refresh()` — при необходимости снова получает `TMP_Text`; если `key` не пустой, ставит `label.text = GameText.Get(key)`.

Метода `Bind` больше нет: подписи меню и сцен назначаются компонентом и полем `key` в сцене.

## 4. Переменные и параметры Inspector

- `key` — публичная строка, стабильный ключ StringTable (`menu.new_game`, `game.title`, `inventory.title` и т.п.).
- `label` — приватный кеш `TMP_Text`, не редактируется.

Требования: `[DisallowMultipleComponent]` и `[RequireComponent(typeof(TMP_Text))]`.

## 5. Связи с другими системами

`GameText` читает Unity StringTable из `Resources/Localization` и сообщает о смене языка. `LocalizedLabel` обновляет только текст, не трогает события кнопок. Компоненты есть в `MainMenu`, `SampleScene` (инвентарь/подсказки) и `BattleScene`.

## 6. Пример работы

`MainMenu/Title` содержит `LocalizedLabel.key = game.title`; при загрузке сцены текст становится `FALSE MEMORY`, при смене языка обновляется без перезагрузки.

## 7. Настройка в Unity

Добавьте компонент на GameObject с `TMP_Text` и укажите ключ. Для нового текста сначала добавьте запись в StringTable (`GameText Shared Data` + `GameText_en-US`), затем тот же ключ в `key`. Не добавляйте компонент на объект без TMP-текста.

## 8. Возможные проблемы и проверки

- Неизвестный ключ даёт `[key]` в тексте — проверьте StringTable.
- Компонент не `ExecuteAlways`: в редакторе без Play текст обновляется только после запуска или ручной установки.
- При выключенном объекте `OnEnable` не срабатывает до включения — это ожидаемо для скрытой панели настроек.
- Английские подписи меню проверены PlayMode-тестом `LocalizationFlowTests`.
