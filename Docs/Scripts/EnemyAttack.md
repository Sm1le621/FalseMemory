# EnemyAttack

## 1. Название и назначение

Исходник: `Assets/Scripts/EnemyAttack.cs`.

Устаревший контактный урон врага в исследовании. Если на объекте есть `BattleEncounter`, компонент не наносит урон: пошаговые встречи полностью заменяют этот путь.

## 2. Как работает

`OnCollisionStay2D` вызывается при физическом контакте тел (нетриггерный коллайдер). Компонент проверяет наличие `BattleEncounter` и при его наличии сразу выходит. Иначе, если объект столкновения имеет тег `Player`, раз в `attackCooldown` берётся `Health` игрока и вызывается `TakeDamage(damage)`.

## 3. Методы и функции

- `OnCollisionStay2D(Collision2D collision)` — Unity callback; наносит контактный урон только без `BattleEncounter` и только объекту с тегом `Player`. После удара записывает в `nextAttackTime` момент `Time.time + attackCooldown`.

## 4. Переменные и Inspector

- `damage` — урон за касание, по умолчанию 10.
- `attackCooldown` — минимальный интервал между ударами, по умолчанию 1 секунда.
- `nextAttackTime` — внутреннее состояние, не редактируется.

## 5. Связи

Требуются `Collider2D` без `Is Trigger` и, для цели, `Health` на объекте с тегом `Player`. `BattleEncounter` не выключает компонент, а служит для него признаком: если он есть на враге, `OnCollisionStay2D` сразу выходит и урон не наносится. `BattleTransition` временно выключает `EnemyAttack` на время боя.

## 6. Пример

Скелет без `BattleEncounter` касается игрока: раз в секунду игрок теряет 10 HP. В текущей сцене у скелета есть `BattleEncounter`, поэтому урон не применяется — начинается пошаговый бой.

## 7. Настройка в Unity

Компонент можно оставить на враге для старых сцен. В основной игре используется `BattleEncounter`; `EnemyAttack` будет автоматически пропускать урон. Для контактного урона нужен нетриггерный коллайдер и тег `Player`.

## 8. Возможные проблемы

`OnCollisionStay2D` может вызываться у выключенного поведения, поэтому проверка `BattleEncounter` обязательна. Триггерные коллайдеры не дают этого callback. Урон не учитывает защиту и не запускает бой. Не используй одновременно контактный урон и `BattleEncounter` без понимания приоритета.
