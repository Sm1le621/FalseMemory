# ItemPresentation

## 1. Название и назначение

Исходник: `Assets/Scripts/Inventory/ItemPresentation.cs`.

Статический класс оформления предметов: цвет ячейки, название слота/типа, строка бонусов и полное описание для окна/подсказки. Не меняет боевые значения и не содержит локализации.

## 2. Как работает

`CellColor` смешивает тёмный фон с цветом заполненной/пустой ячейки в зависимости от выделения. `SlotName` возвращает `Weapon` или `Chest`. `TypeName` определяет подпись по категории. `BonusText` собирает `ATK +N`, `DEF +N`, а для `BattleConsumable` — восстановление HP/MP. `Description` собирает имя, тип, бонусы, описание и цены, экранируя `<`/`>` в пользовательском тексте.

## 3. Методы и функции

- `CellColor(ItemData item, bool highlighted)` → `Color`; цвет ячейки.
- `SlotName(EquipmentSlot slot)` → `string`; `Weapon`/`Chest`.
- `TypeName(ItemData item)` → `string`; `Weapon`, `Chest` для брони или `Consumable`.
- `BonusText(ItemData item)` → `string`; бонусы и эффекты зелья через `•`.
- `Description(ItemData item, int count)` → `string`; многострочное описание для TMP.
- `Escape(string text)` — заменяет `<`/`>` на `‹`/`›`, чтобы контент не ломал TMP-разметку.

## 4. Переменные и Inspector

Собственных полей нет. Цвета заданы константами в коде: тёмный фон, заполненная и пустая ячейка. Текст формируется из `ItemData` и `BattleConsumable`.

## 5. Связи

Используется `InventoryWindow`, `InventoryTooltip`, `InventorySlotView`, `EquipmentSlotView` и тестами. Читает `ItemData`/`BattleConsumable`; не зависит от `InventoryState`.

## 6. Пример

Iron Sword с `attack = 5` даёт строку `ATK +5`. Potion с `healing = 30` — `Restores up to 30 HP`. Описание начинается с жирного имени, затем тип и бонусы; при количестве больше 1 добавляется `×N`.

## 7. Настройка в Unity

Компонент не прикрепляется. Текст и цвета меняются в этом классе; данные — в ассетах предметов. Для нового типа предмета потребуется расширить `TypeName`/`BonusText`.

## 8. Возможные проблемы

Описание экранирует только угловые скобки, не все возможные TMP-теги. Названия слотов всегда английские. Для брони `TypeName` возвращает имя слота (`Chest`), а не слово `Armor`. Нет редкости и цветовой градации по ней.
