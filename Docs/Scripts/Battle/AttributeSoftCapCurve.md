# AttributeSoftCapCurve

## 1. Название и назначение

Исходник: `Assets/Scripts/Battle/AttributeSoftCapCurve.cs`. Serializable интеграл кусочно-постоянных приростов характеристики. Не компонент и не отдельный владелец характеристик.

## 2. Как работает

Serializable интеграл кусочно-постоянных приростов характеристики. Не компонент и не отдельный владелец характеристик. Использует прежние10 характеристик и одного владельца ресурсов/экипировки; отдельная система классов/сохранений не создаётся.

## 3. Методы и функции

Evaluate(value) суммирует вклад диапазонов до value; после последнего порога применяется последний gain. При value≤0 возвращает0. Дубли/отрицательные thresholds не дают отрицательных диапазонов. Rate(index) безопасно берёт последний доступный gain, NaN/Infinity/отрицательные значения даёт0. NextCap(value) возвращает ближайший строго больший порог либо99. Default(attribute) создаёт10 согласованных кривых; Unity callbacks отсутствуют.

## 4. Переменные и Inspector

attribute — enum существующих10 stats. thresholds int[] и gains double[] редактируются внутри rules.softCaps, не внутри Player. STR/DEX/MAG20/55/80 с1/.5/.25/.1; AGI/WIS/CHA/MCR30/60 с1/.5/.2; END30/50/60 с1/.5/.25/.1; VIT40/60 с8/4/1; INT40/60 с4/2/.5.

## 5. Связи

CharacterAttributeRules/CharacterAttributes/BattleUnit/ItemData/EquipmentState, GameText и существующая InventoryWindow. Для tests используются NUnit/Unity Test Framework; для Editor AssetDatabase/EditorSceneManager. Назначение конкретных связей раскрыто выше.

## 6. Пример

VIT20: интеграл160 минус baseline80, к базовым100HP добавляется80. Далее40→340HP/60→420/99→459.

## 7. Настройка в Unity

Вложенный объект CharacterAttributeRules.softCaps. Не прикреплять к GameObject. Порог — снижение отдачи, не запрет повышения; все gains должны быть конечными положительными и невозрастающими.

## 8. Возможные проблемы

Вложенный объект CharacterAttributeRules.softCaps. Не прикреплять к GameObject. Порог — снижение отдачи, не запрет повышения; все gains должны быть конечными положительными и невозрастающими.
