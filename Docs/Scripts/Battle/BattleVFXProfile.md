# BattleVFXProfile

## 1. Название и назначение

Исходник: `Assets/Scripts/Battle/BattleVFXProfile.cs`.

ScriptableObject с художественными параметрами визуального эффекта: форма траектории, цвет, размер, длительность, частицы и необязательный покадровый эффект. Профиль не содержит игровой логики и не влияет на урон или MP.

## 2. Как работает

`BattleVFXController` читает профиль и проигрывает эффект на портрете цели. Если профиль не назначен, используется fallback `fireProfile`. Кадры эффекта лежат в `.anim`-клипе, на который указывает `effectController`; частицы двигаются по выбранной форме. Ассет можно переиспользовать для разных заклинаний с похожим видом.

## 3. Методы и функции

Собственных методов и callbacks нет. Unity создаёт экземпляр через `Create Asset Menu`. Перечисление `BattleVFXShape` задаёт три траектории: `Rising`, `Orbit`, `Burst`.

## 4. Переменные и Inspector

- `shape` — форма движения частиц.
- `color` — цвет частиц.
- `particleSprite` — необязательный спрайт частицы; без него рисуется цветной квадрат.
- `effectController` — Animator-контролер с клипом `Effect`; если не назначен, показываются только частицы.
- `frameCount` — число кадров в клипе (для счётчика `CurrentFrame` и тестов), по умолчанию 8.
- `frameSize` — размер кадра в UI-единицах, 32…256, по умолчанию 128.
- `duration` — длительность, 0…2, по умолчанию 0.45.
- `particleCount` — количество частиц, 4…24, по умолчанию 12.
- `particleSize` — размер частицы, 1…24, по умолчанию 8.
- `radius` — радиус движения, 0…100, по умолчанию 42.
- `FireVisual`: 8 кадров 64×64, `duration = 0.6`, `frameSize = 128`, оранжевые частицы.

## 5. Связи

`BattleSpell.visualEffect` и `BattleVFXController.fireProfile` ссылаются на ассеты. `BattleVFXController` читает данные, `BattleManager` вызывает показ после успешного применения. Клип и контролер эффекта собирает `SpriteAnimationAssetBuilder`. Ассеты лежат в `Assets/Settings/Battle/VFX`.

## 6. Пример

Fire с профилем `FireVisual` показывает 8 кадров и 12 оранжевых частиц; урон и расход MP при этом считает `BattleAbilities`, а не профиль. Если у заклинания нет профиля, эффект всё равно проигрывается с fallback-цветом.

## 7. Настройка в Unity

Создай ассет через `Assets → Create → FalseMemory → Battle VFX Profile`, назначь его в `BattleSpell.visualEffect` или в `BattleVFXController.fireProfile`. Компонент к GameObject не прикрепляется. Контролер и `frameCount` заполняет `FalseMemory → Animation → Rebuild sprite animations`. Кадры должны быть импортированы как Sprite 2D с Point filtering.

## 8. Возможные проблемы

Профиль меняет только внешний вид. Пустой `particleSprite` даёт цветные квадраты, отсутствие `effectController` — эффект без кадров. Слишком большой `particleCount` ограничивается длиной массива частиц в сцене. `frameCount` должен совпадать с числом кадров в клипе, иначе счётчик `CurrentFrame` будет неверным. Новые формы траектории требуют расширения `BattleVFXShape` и контроллера.
