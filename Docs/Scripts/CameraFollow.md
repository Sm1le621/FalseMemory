# CameraFollow

## 1. Название и назначение

**Исходный файл:** F:/LLM/UUU/Miri/FalseMemory/Assets/Scripts/CameraFollow.cs.

Плавное следование мировой камеры за игроком.

## 2. Как работает

После Update приближает позицию к target.position+offset через Lerp с коэффициентом1−exp(−max(0,smoothSpeed)×deltaTime); без target не действует.

## 3. Методы и функции

`LateUpdate()` — каждый кадр после Update читает target/smoothSpeed/offset/deltaTime, меняет transform.position; void.

## 4. Переменные и параметры Inspector

target — сериализованный Transform Player. smoothSpeed — код 5, >0, частота экспоненциального приближения1/с; отрицательное значение трактуется как0. offset — Vector3, код (0,0,−10).

## 5. Связи с другими системами

Main Camera SampleScene. BattleTransition скрывает мировую камеру на время боя; BattleScene имеет свою.

## 6. Пример работы

Player смещается вправо → камера постепенно следует с прежним Z-смещением.

## 7. Настройка в Unity

На Main Camera SampleScene. Назначь Target=Player, Offset с отрицательным Z и положительный Smooth Speed. Не добавляй в BattleScene следование к скрытому мировому Player; там собственная камера.

## 8. Возможные проблемы и проверки

Нет границ карты или Cinemachine. smoothSpeed=0 останавливает следование. Код/компонент проверены; плавность вручную здесь не оценивалась.

LateUpdate читает интерполированный Transform исходного Player. Частота физики и orthographic size5 не меняются. PixelPerfectCamera на мировой камере отсутствует; настройки pixel art импорта прежние.
