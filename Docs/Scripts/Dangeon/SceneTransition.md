# SceneTransition

## 1. Название и назначение

**Исходный файл:** `Assets/Scripts/Dangeon/SceneTransition.cs`.

Триггер входа в пещеру/дверь. Когда объект с тегом `Player` входит в коллайдер-триггер, скрипт запускает переход в другую сцену через `SceneTransitionManager`.

## 2. Как работает

В `Awake` проверяется, что имя целевой сцены не пустое. Если поле осталось пустым, подставляется `Dungeon` и в Console выводится предупреждение.

В `OnTriggerEnter2D` скрипт:

1. Проверяет тег вошедшего объекта — переход разрешён только для `Player`.
2. Не начинает переход, если `BattleTransition` уже выполняет переход или идёт бой.
3. Находит или создаёт `SceneTransitionManager`.
4. Не начинает второй переход, пока менеджер занят.
5. Вызывает `ChangeScene` с именем сцены и точкой появления.

Если переход не удалось начать, в Console выводится предупреждение.

## 3. Методы и функции

- `Awake()` — Unity-вызов при создании объекта. Подставляет `Dungeon`, если `targetSceneName` пустой; ничего не возвращает.
- `OnTriggerEnter2D(Collider2D other)` — Unity-вызов физики 2D при входе в триггер. Проверяет тег `Player`, состояние боя, получает менеджер и вызывает `ChangeScene`. Возвращаемого значения нет; запускает корутину перехода.

## 4. Переменные и Inspector

- `targetSceneName` — строка, имя сцены для загрузки. По умолчанию в коде `Dungeon`. Сцена должна быть в Build Settings.
- `useSpawnPosition` — bool, по умолчанию `true`. Если включено, игрок ставится в `spawnPosition` новой сцены.
- `spawnPosition` — `Vector2`, по умолчанию `(0, 0)`. Точка появления игрока в новой сцене.

## 5. Связи с другими системами

- `SceneTransitionManager` — выполняет загрузку сцены и переносит Player, HP/MP-полосы, инвентарь, EventSystem, `BattleTransition` и Global Light 2D.
- `BattleTransition` — источник проверки `IsTransitioning`/`EncounterActive`; во время боя вход запрещён.
- `PlayerController` и `Rigidbody2D` Player — нужны для физического входа в триггер.
- Build Settings — без сцены `Dungeon` переход не начнётся.

## 6. Пример работы

В `SampleScene` у входа в пещеру должен лежать объект с `BoxCollider2D` (Is Trigger) и `SceneTransition`. Игрок подходит и касается триггера. Скрипт проверяет тег, вызывает менеджер, и после загрузки `Dungeon` игрок появляется в точке `(0, 0)` с теми же HP/MP, инвентарём и экипировкой.

На диске в сохранённом `SampleScene.unity` этого объекта пока нет: он добавлен в открытом Editor и должен быть сохранён перед Play Mode.

## 7. Настройка в Unity

1. Создайте пустой объект или используйте объект входа в пещеру.
2. Добавьте `BoxCollider2D` и включите `Is Trigger`.
3. Добавьте компонент `SceneTransition` на тот же объект, где находится коллайдер.
4. В `Target Scene Name` укажите `Dungeon`.
5. При необходимости включите `Use Spawn Position` и задайте `Spawn Position`.
6. Убедитесь, что у Player есть `Rigidbody2D`, `Collider2D` и тег `Player`.
7. Сохраните сцену и добавьте `Dungeon` в Build Settings.

Скрипт работает и без второго объекта-менеджера: `SceneTransitionManager` создаётся автоматически при первом входе.

## 8. Возможные проблемы

- **Переход не начинается.** Проверьте тег Player, наличие `Rigidbody2D`, `Is Trigger` у коллайдера и имя сцены.
- **Ошибка «not in Build Settings».** Добавьте `Dungeon` в File → Build Profiles → Scene List.
- **Два перехода подряд.** Менеджер блокирует повторный запуск, пока не закончит загрузку.
- **Скрипт не получает `OnTriggerEnter2D`.** Компонент и коллайдер должны быть на одном GameObject, либо событие должно приходить на объект с коллайдером.
- **Игрок появился не там.** Проверьте `useSpawnPosition` и `spawnPosition`; координаты задаются в мировых единицах сцены.
- **Сцена не сохранена.** Изменения, сделанные только в открытом Editor без сохранения, не попадут в файл сцены.

## 9. История изменений

- 2026-11-09 — скрипт переписан под общий менеджер переходов: добавлены проверка боя, `SceneTransitionManager`, точка появления и английские предупреждения. Ранее скрипт напрямую вызывал `SceneManager.LoadScene` и не переносил Player между сценами.
