# PixelBattleAssetBuilder

## 1. Название и назначение

Исходник: Assets/Editor/PixelBattleAssetBuilder.cs.

Editor-инструмент создания оригинальных native PNG64×64 на целочисленной пиксельной сетке. Исходник рисунка — этот C#-код; крупный AI-референс не сэмплируется.

## 2. Как работает

Формирует RGBA-пиксели фиксированной палитры, пишет новые PNG, импортирует через AssetDatabase и задаёт Point/Uncompressed/без mipmaps/PPU100. Проверяет существующие файлы перед записью; не заменяет старую графику.

## 3. Методы и функции

`Generate()` (меню FalseMemory/Art/Generate native 64px battle art) создаёт15 Skeleton и8+8 Fire/Heal. `GenerateImpact()` отдельным меню создаёт64px Hit. `Skeleton(pose,frame)`, `Fire(frame)`, `Heal(frame)` возвращают Grid. `Skull`, `Bone`, `Sword`, `Shield` добавляют элементы. Grid.Px проверяет границы и преобразует координаты сверху-вниз в массив Unity; Rect заполняет, Line — целочисленный Bresenham, Poly — заполнение многоугольника, Ellipse — целочисленный контур. Unity callbacks отсутствуют.

## 4. Переменные и Inspector

SkeletonRoot=Assets/Art/Enemies/Skeleton64, VfxRoot=Assets/Art/VFX, фиксированная Palette22 включая прозрачность. Холст64×64; альфа0/255. Позиции/цвета заданы кодом; Inspector-параметров нет.

## 5. Связи

UnityEditor AssetDatabase/TextureImporter, SpritePose из Runtime. Данные анимации/сценовые ссылки настраиваются отдельно MCP; Generate не меняет сцены/боевой баланс.

## 6. Пример

Первый вызов Generate создаёт Skeleton-Idle-00.png и остальные кадры; повторный вызов отвергает существующие пути. Importer применяет одинаковые параметры.

## 7. Настройка в Unity

Не прикрепляется. Запускать только в Edit Mode. Уже созданные PNG можно редактировать внешним pixel-art редактором; для нового программного варианта использовать новые пути, сохранив исходные .meta и разрешённые ссылки.

## 8. Возможные проблемы

Перезапись намеренно запрещена. Не удалять существующие ассеты ради повторного Generate. Изменение рецепта само по себе не обновляет PNG. Кадры созданы без сглаживания/масштабирования; увеличенные Game View снимки — проверка, а не исходники.
