# Направления и Animator игрока

## Актуальная реализация — 2026-10-13

Утверждённый владельцем крупный герой подключён к существующему Player. Front Down — исходные четыре изображения без уменьшения; отдельный built-in imagegen создал Up, Right, UpRight, DownRight. Left/UpLeft/DownLeft зеркально подготовлены из соответствующих правых изображений, поэтому сторона оружия отражается. Задний ракурс имеет собственные изображения. Качество шага/сходство дополнительных ракурсов требует художественной приёмки; наличие четырёх Sprite не доказывает естественность походки.

## Компоненты и последовательность

PlayerController сохраняет прежний нормализованный Input System/WASD/стрелки, последний ненулевой вектор, bool isMoving и float MoveX/MoveY/LastMoveX/LastMoveY. Два прежних SimpleDirectional2D Blend Tree выбирают Idle/Walk по восьми точкам; диагонали нормализованы. Idle читает LastMove, Walk Move; переходы без Exit Time/задержки. FlipX directional-контроллером не применяется: отражённые левые изображения уже подготовлены в PNG. WorldInputGate и OnDisable сохраняют последнее направление и прекращают физическое движение.

## Кадры, импорт и ссылки

В существующих Assets/Animations/Player64 сохранены GUID шестнадцати клипов, несмотря на историческое имя папки. Walk каждого направления: четыре кадра,8FPS/Loop, ключи0/.125/.25/.375/.5; последний повторяет первый. Idle пока один соответствующий кадр, без дыхательного цикла. Прежние Player_Idle/Walk/Run и PlayerMyproject_Idle/myproject1idle.ase/Idle1.ase остаются резервом, недостижимым из новых default-состояний.

Down512×640, PPU1100/pivot(256,40); остальные384×384, PPU640/pivot(192,20). Одинаковый холст внутри каждого цикла, общая линия стоп, без изменения размеров пикселей при нарезке. Point/без mipmaps/compression, Max Size4096/NPOT None. SpriteRenderer и BattleUnit/Inventory portrait/BattleUI preview используют ApprovedHero_Down_00. Tint SpriteRenderer теперь белый, чтобы не затемнять утверждённые цвета дополнительно. Rigidbody2D/коллайдеры/Transform/камера/скорость сохранены; мирная высота около1.04 единицы. Не изменяются HP/MP/статы и боевые действия.

## Проверки и развитие

ApprovedHeroAssetTests проверяет импорт/четыре разных Sprite/направления/отсутствие Transform-кривых. PlayerDirectionFlowTests проверяет ввод8 направлений, реальную смену кадров, Idle/последний взгляд/блокировку Inventory. Сценарии BattleFlowTests проверяют бой/VFX/возврат. Свежие результаты — [ApprovedHeroIntegration](../ApprovedHeroIntegration.md), правила — [PixelArtStyleGuide](../Guides/PixelArtStyleGuide.md), инструмент — [ApprovedHeroImporter](../Scripts/Editor/ApprovedHeroImporter.md).

## История и ограничения

- 2026-10-12 — подготовлены directional Animator/input, но все клипы использовали статический myproject1idle. Генерация1983×793 тогда отклонялась по прежнему правилу64×64.
- 2026-10-13 — владелец прямо утвердил этот дизайн/разрешение и отменил64×64; результат теперь используется в игре. Историческое отклонение не является действующим ограничением.

Новые ракурсы созданы по референсу, но не утверждены художественно владельцем. Idle статический, полноценные Attack/Hurt/Death игрока пока отсутствуют: существующее боевое представление использует прежние эффекты движения UI. Левые виды зеркальны, движения некоторых поз могут выглядеть неглубокими. Нужна ручная оценка перед дальнейшей разработкой.
