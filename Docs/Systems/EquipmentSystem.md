# Экипировка

Семь слотов: Weapon, Head, Chest, Legs, Boots, Accessory1/2. EquipmentController.State на исходном Player хранит владение, ItemData — определения. Надевание заменяет одну вещь и возвращает предыдущую в исходную ячейку; полная сумка допускает замену. Снятие целиком отменяется при нехватке места. Рекурсивные запросы из Changed отклоняются.

Бонусы вычисляются заново из семи вещей, не прибавляются в базовые поля. BattleUnit.EffectiveAttack/Defense/MagicAttack/MagicDefense/Speed читают базу+бонус. HP/MP/EXP не меняются. Данные: Sword ATK5, Staff MATK4, Armor DEF4, Helmet DEF2. Ограничения Fits/requiredLevel, предметы по1. Формулы боя используют эти значения с4.5; на4.4 проверены модель/UI/характеристики, не заявляется увеличенный урон.

Окно I: выбрать вещь → Экипировать либо подходящий правый слот. При выбранной совместимой вещи слот заменяет/надевает её; иначе нажатие надетого слота снимает вещь. Автовыбор аксессуара — первый свободный, иначе1. Суммарные характеристики справа. Экипировка в BattleScene запрещена. Require Unit/Inventory/Window назначены в SampleScene через MCP, мир/данные не копируются.

Расширение: новые определения через данные; новые характеристики централизованно в ItemStatBonus/Unit, не += при каждом Refresh. Бонусы HPMP/классов/роста будущий этап5. Сохранение на диск этап9, текущая сессия сохраняет State при hide/show. EditMode11 случаев и PlayMode кнопки/бонусы; эстетика/курсор владельцем.
