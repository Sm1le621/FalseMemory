# Экипировка

Восемь слотов: Weapon, Head, Chest, Legs, Boots, Accessory1/2, Gloves. Gloves добавлен в конец enum (7); прежние Accessory1/2 остаются5/6. EquipmentController.State на исходном Player хранит владение, ItemData — определения. Надевание заменяет одну вещь и возвращает предыдущую в исходную ячейку; полная сумка допускает замену. Снятие целиком отменяется при нехватке места. Рекурсивные запросы из Changed отклоняются.

Бонусы вычисляются заново из восьми вещей, не прибавляются в базовые поля. BattleUnit.EffectiveAttack/Defense/MagicAttack/MagicDefense/Speed читают базу+бонус. HP/MP/EXP не меняются. Данные: Sword ATK5, Staff MATK4, Armor DEF4, Helmet DEF2. Ограничения Fits/requiredLevel, предметы по1. С4.5 Manager и Abilities используют итоговые значения: Sword повышает базовый физический урон10→15, Armor+Helmet даютDEF14/ответ1, Staff Fire19→23 при прежней цене8MP. Проверено сценариями без RNG-крита/защиты; штатные шансы могут менять результат.

Окно I: выбрать вещь → Экипировать либо подходящий правый слот. При выбранной совместимой вещи слот заменяет/надевает её; иначе нажатие надетого слота снимает вещь. Автовыбор аксессуара — первый свободный, иначе1. Суммарные характеристики под персонажем слева. Экипировка в BattleScene запрещена. Require Unit/Inventory/Window назначены в SampleScene через MCP, мир/данные не копируются.

Расширение: новые определения через данные; новые характеристики централизованно в ItemStatBonus/Unit, не += при каждом Refresh. Бонусы HPMP/классов/роста будущий этап5. Сохранение на диск этап9, текущая сессия сохраняет State при hide/show. EditMode12 случаев и PlayMode кнопки/бонусы; эстетика/курсор владельцем. [Скрипты](../README.md), [отчёт](../InventoryStage4.md).

2026-10-12 — UI по референсу: кнопки слотов вокруг существующего портрета, иконки/редкость/hover читают State без копирования владения. Подробности [InventoryRedesign](../InventoryRedesign.md). Предметов Gloves/Legs/Boots/Accessory в демонстрационном наборе нет; модель проверена параметризованными тестами, новые определения можно создать через ItemData.
