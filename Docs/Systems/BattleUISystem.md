# Интерфейс боя

BattleUI сохраняет управление командами, обратные вызовы, защиту от удержания Enter и прокрутку длинных списков. BattleHUD отвечает только за оформление и плавные полосы.

Верх: имя/HP противника, раунд и сообщение действия. Центр: исходные спрайты, скелет слева/герой справа. Низ: Player/LV/HP/MP, три полосы, Potion/EXP/Defend и пять команд. Magic/Items занимают ту же панель и возвращаются через Escape без хода; отдельная цветовая подсветка показывает выбор/недоступность.

Макет 960×540 центрирован, Canvas масштабируется по высоте; на 21:9 панели не растягиваются. BuildLayout в BattleHUD только для Editor/MCP; существующие объекты сохраняются. Расширять оформление внутри BattleContent, не записывая игровые ресурсы из UI. Настройки и ограничения: [BattleHUD](../Scripts/Battle/BattleHUD.md), [BattleUI](../Scripts/Battle/BattleUI.md). Ручная оценка читаемости обязательна для владельца; тесты проверяют ресурсы/ввод/полосы.
