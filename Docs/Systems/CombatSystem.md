# Пошаговые сражения

## 1. Назначение

Бой один на один со скелетом, пять команд, очередь по Speed и победа/поражение/побег.

## 2. Общая логика

Раунд получает каждого живого участника один раз. Защита действует до начала следующего собственного хода. Принятая команда блокирует ввод немедленно.

## 3. Основные компоненты

BattleEncounter, BattleTransition, BattleManager, BattleUnit, BattleTurnOrder, BattleCommandGate, BattleCalculator, EnemyBattleAI, BattleUI.

## 4. Взаимодействие скриптов

Encounter передаёт пару Transition; Transition сохраняет объекты и загружает BattleScene. Manager обращается к Unit/Health, Calculator/Abilities и UI.

## 5. Последовательность событий

Касание тел → блокировка мира → дополнительная BattleScene → выбор игрока → действие → ход врага → новый раунд либо исход. Победа: опыт/результаты/ручной возврат; побег: автоматический возврат; поражение: новая игра/меню.

## 6. Настраиваемые параметры

Player ATK15 DEF8 SPD10 HP100; Enemy ATK12 DEF5 SPD7 HP60. Rules: actionDelay0.8, Defend×0.5, enemyDefendChance0.2, крит×1.5. Каждый Unit: crit0.1, miss0.05.

## 7. Использование в Unity

Запускать SampleScene или MainMenu → Start; войти в контакт с Enemy. В BattleScene назначен BattleUI с пятью кнопками. Нужны все три сцены в Build Profiles Scene List, тег Player, физические Collider2D/Rigidbody2D и Transition.rules.

## 8. Расширение

Для новой физической формулы менять Calculator с тестами. Новые эффекты — Abilities/данные. Для партии потребуется расширить Manager и выбор целей; generic очередь уже умеет несколько участников.

## 9. Ограничения и проверки

Нет партии/тактики врага/уровней. Fire не критует и не промахивается. Код и 40+17 тестов проверены; статистический баланс и удобство оценивает владелец.
