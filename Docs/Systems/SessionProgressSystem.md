# Опыт и состояние игровой сессии

## 1. Назначение

Накопление EXP и сохранение ресурсов между текущими боями.

## 2. Общая логика

Мир остаётся загруженным, поэтому Player/Enemy не заменяются копиями. EXP хранится в Unit, награда помечается выданной в Transition.

## 3. Основные компоненты

BattleUnit, Health, Inventory, Transition, Manager, UI.

## 4. Взаимодействие скриптов

Manager при победе вызывает TryGrantVictoryExperience; Unit.AddExperience ограничивает int.MaxValue. ReturnAfterVictory отключает врага; ReturnAfterEscape оставляет его живым.

## 5. Последовательность событий

Победа → EXP+20 один раз → результаты → возврат с прежними ресурсами. Побег → возврат без EXP → защитный таймер → повторный бой. Новая игра/Single загрузка сбрасывает сессию.

## 6. Настраиваемые параметры

Player Level1 EXP0, Enemy Reward20; HP100/MP30/Potion3 в новой сессии. Level не увеличивается автоматически.

## 7. Использование в Unity

Для результата победить скелета, проверить четыре строки окна и ресурсы на карте. Для повторного боя сначала сбежать; побеждённый враг повторно недоступен.

## 8. Расширение

Будущие Level-up/классы/рост характеристик должны расширить модель Unit/прогресса. Полноценное сохранение потребует идентификаторов объектов и данных отдельного файла.

## 9. Ограничения и проверки

Нет дискового SaveSystem, восстановления после закрытия игры и сохранения при произвольной выгрузке карты. Нельзя трактовать PlayerPrefs меню как готовый Save. Однократный EXP и ресурсы после победы/побега проверены PlayMode.
