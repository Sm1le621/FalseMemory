# Взаимодействие в мире

На4.3 работает подбор предметов, NPC/диалоги/сундуки ещё не созданы. Один PlayerInteractor на Player принимает E; WorldInputGate блокирует его при открытом окне. IWorldInteractable объединяет Prompt/Available/TryInteract. Поиск Physics2D каждые0.15с в радиусе1.2 использует переиспользуемый List и ближайшую доступную цель.

WorldItemPickup резервирует выдачу до уведомления инвентаря. Полный отказ не списывает предмет/не выключает объект; успех изменяет единственный InventoryState и выключает pickup. Быстрые повторные вызовы не дают копий. BattleTransition скрывает/показывает исходную карту, поэтому подобранные дочерние объекты остаются выключенными в текущей сессии.

Unity: PlayerInteractor Unit/Gate/две TMP-ссылки; WorldItemPickup prefab Collider2D trigger/спрайт/ItemData/количество/уникальный worldId. Семь тестовых instance в SampleScene/TestLoot с временными значками. Новое размещение обязано иметь собственный ID. Gold Coin не создан, валюта отдельно.

Расширение: NPC/сундук реализуют тот же контракт и получают общий gate. Дисковое сохранение worldId/Collected — этап9, не текущая функция. Линия видимости не проверяется; сейчас близость. PlayMode проверяет E/полноту/однократность/блокировку, художественное размещение и настоящий курсор — ручная оценка. [Скрипты](../README.md), [отчёт](../InventoryStage4.md).
