# FalseMemory — подэтап5.6: окно Character

2026-10-26. Создано отдельное окно по C внутри существующей SampleScene. Inventory30/Equipment9, PlayerController, Health, боевые сцены и анимации не переписывались.

## Подключение и поведение

- Player.CharacterWindow связан с CharacterPanel/Backdrop/Tooltip под прежним InventoryCanvas. Используется существующий CanvasScaler и TMP-шрифт; тёмные панели и золотистые рамки созданы штатными UI-компонентами.
- C открывает/закрывает, Esc закрывает, I переключает на Inventory; C из Inventory переключает обратно. WorldInputGate блокирует движение/взаимодействие. Другой modal owner, смерть и encounter запрещают открытие; деактивация мира освобождает блокировку.
- Attributes:10 строк base/gear/effective, свободные points, кнопки +; справа и в tooltip — назначение, источники, следующий cap и реальное изменение следующего очка после округления. Preview копирует значения и не меняет игрока. Base≤99, двойной callback вframe не тратит второй point; повышение MaxHP/MP не лечит.
- Combat Stats:9 показателей включая initiative/Holy/miss, действующее оружие сScaling/requirements. Abilities:6 записей, требования/availability/MP, кнопка Learn за отдельныеLP. Equipment:9 настоящих слотов и описание выбранного; менять вещи следует вInventory.
- Обновление через прежние StatsChanged/ProgressChanged/Learning.Changed; текущее HP/MP дополнительно отслеживается при открытом окне, потому что Health не имеет события ресурсов.
- Исправлено прежнее ошибочное описание WIS: теперь MagicDefense/WISScaling/Holy, прямо указано отсутствиеMP. Tooltip переограничивается после изменения разрешения в LateUpdate.
