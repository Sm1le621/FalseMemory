# FalseMemory — документация

**FalseMemory** — 2D pixel-art RPG на Unity 6. Игрок ходит по миру, касается скелета и попадает в пошаговый бой в стиле старых JRPG. Есть инвентарь на 30 слотов, экипировка (оружие и броня), магия Fire, подземелье с боссом (из него выпадает меч Excalibur) и меню паузы.

Документация объясняет **как устроены скрипты и как объекты Unity взаимодействуют между собой**. Рассчитана на человека, который знает C# и ООП, но не работал с Unity.

## Проект в цифрах

- 4 сцены: `MainMenu`, `SampleScene` (мир), `BattleScene` (бой), `Dungeon` (подземелье).
- 39 игровых скриптов (`Assets/Scripts`) + 16 файлов тестов (`Assets/Tests`).
- Боевые команды: **Attack, Magic, Defend, Flee**. Зелья пьются только из инвентаря вне боя.
- Сохранения игры нет; `PlayerPrefs` хранит только громкость и полноэкранный режим.
