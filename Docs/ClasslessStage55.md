# FalseMemory — подэтап5.5: изучение способностей

2026-10-26. Бесклассовое изучение расширяет прежние BattleSpell/BattleAbilities. Все игровые тексты находятся в English StringTable; документация остаётся русской.

## Реализация

- AbilityLearning на Player хранит стабильные learnedIds и отдельные Learning Points. Стартовый запас3 LP, выдача1 LP/level, цена каждого нового умения1 LP; параметры настраиваются. Это тестовая экономика до будущих учителей/NPC, attribute points не расходуются.
- Проверяются каталог, ID, уровень и эффективные характеристики. TryLearn атомарен, повторный вход/изучение запрещены, во время боя обучение закрыто. Снятие экипировки после обучения не забывает умение.
- Fire/Heal остаются известными через прежний unit.spells; их прежние эффект/стоимость/MP не заменены. Новые требования Fire MAG15/INT12 относятся к обучению, не лишают стартового игрока уже известного заклинания.
- Новые4 ассета: Power Strike STR20/6MP/сила×1.5; Quick Strike DEX18+AGI15/5MP/×1.15/точность+20п.п.; Greater Heal MAG20+WIS20/12MP/50 base; Sacred Strike WIS25+STR15/8MP/×1.2/Holy8 только отмеченным целям.
- BattleSpell содержит ID/name/description/requirements/level/learningCost/MP/effect/damageType/scaling/target. Learned/availability принадлежат состоянию игрока. Техники используют прежний ResolvePhysical с crit/miss/Defend; магия/лечение — прежние пути. MCR применяется один раз, максимум30%, платная способность не бесплатна.
- KnownAbilities объединяет старые и новые изученные; они появляются в существующем меню Magic. Нового дублирующего менеджера ресурсов/сохранений нет. UI обучения добавляется в5.6.

## Ограничения

Нет постоянного save: всё хранится в игровой сессии, New Game начинает заново. NPC-учителя/книги ещё не реализованы. Physical-техники пока находятся в Magic вместе с заклинаниями. Новая графика и звуки для них не создавались; Greater Heal использует существующий Heal VFX. Следующий шаг5.6 — Character UI с просмотром требований и кнопками обучения.
