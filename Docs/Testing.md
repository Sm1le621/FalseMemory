## Что подтверждают тесты

Edit Mode проверяет урон/Defense/Defend, очередь Speed и смерть участника, gate, Fire8 MP, недостатокMP, Heal/HP-лимит, Potion/Count, EXP/переполнение, crit/miss/порядок бросков, seed и формулу побега.

Play Mode проверяет контактный запуск ровно одного боя, Attack/Defend и прежний Health, клавиатурный ввод/удержание Enter, меню/отмену/недоступность и длинные списки, двойные команды/расходы, зелёное фактическое лечение, крит/промах, неудачный и успешный побег с повторной встречей, смерть во время выбора и до применения магии, победу/однократный опыт, ресурсы/HUD/врага при возврате, поражение/новую игру/главное меню. Полный комбинированный сценарий заканчивается 88 HP/6 MP/2 Potion/25 EXP/Level1.

Кнопочные проверки вызывают onClick.Invoke, а клавиатурные используют Input System. Реальный физический контакт используется в отдельном тесте; некоторые короткие сценарии запускают TryBegin напрямую. Отчёт не означает, что каждый сценарий проверен ручным нажатием мышью.

## Как проверить вручную

Открой SampleScene → Play → кликни Game View → подойди к скелету. Проверь читаемость пяти команд, Fire8 MP, Heal6 MP, Potion и Escape без расхода хода; побег должен сохранить ресурсы и дать время отойти. Победа должна показать+20 EXP и вернуть в мир без побеждённого скелета. В отдельном запуске поставь Current Health=1 только в Play Mode и проверь Game Over/новую игру.

Подробная инструкция с ожидаемыми числами: [BattleStage2](BattleStage2.md#ручная-проверка-в-play-mode). Для документации дополнительная ручная игровая проверка не блокирует локальный коммит; удобство/баланс остаются оценкой владельца.
