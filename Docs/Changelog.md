# История значимых изменений FalseMemory

Записи дополняются по факту задач. Дата первичной документации не является датой создания каждого исходного скрипта.

## 2026-10-11 — 3.5: переходы и исходы

Добавлены BattleScreenFade, SmoothStep-затемнение 0.5 секунды, проявление UI/результатов, исчезновение погибшего и уход при Flee. Game Over использует существующее окно и меню. Только временный overlay переживает Restart/Main Menu, не Player/Enemy. MCP сохранил CanvasGroups/ссылки и правила. Повторные встречи/расходы/награды остаются под прежними блокировками; добавлена проверка входа/поражения.

## 2026-10-11 — 3.4: звук боя

Добавлены AudioProfile/Controller, AudioSource и BattleMixer/Master через MCP. UI/Manager отправляют события без связи с расчётами. Пустые ссылки безопасны и намеренны: подходящего аудио нет, сторонние файлы не скачивались. Общая громкость SettingsMenu учитывается; слышимость/баланс будущих клипов не заявляются проверенными. Добавлен Play Mode тест отсутствующих клипов/громкости.

## 2026-10-11 — 3.3: магические эффекты

Добавлены профили/контроллер VFX, Fire/HealVisual и их ссылки в существующих Fire/Heal; через MCP подключён контроллер в BattleScene. Fire использует подъём огня, Heal/Potion — зелёные ромбы; кастующий подсвечивается. Стоимость MP/HP/порядок сохранены; эффект применяется после успешного расчёта. Добавлен тест окончания эффекта/отсутствующего VFX. Новые игровые заклинания не создавались.

## 2026-10-11 — 3.2: анимации действий

Добавлены BattlePresentation, выпад/возврат, реакция успешного попадания/крита, символ защиты, всплывающий урон и MISS без вспышки. Manager применяет эффект ровно один раз и проверяет смерть после windup. Компоненты/ссылки/символы сохранены MCP в BattleScene. Две новые Play Mode проверки защищают отмену при смерти и работу без визуального компонента. Временные Transform/Image-анимации позже заменяются кадрами владельца.

## 2026-10-11 — этап 3.1: интерфейс боя

Добавлены BattleHUD, три неинтерактивные плавные полосы, LOW HP, рамки панелей и цветовое выделение команд. Прежние UI-объекты перенастроены через MCP и сохранены в BattleScene; формулы/ресурсы/очередь не менялись. Добавлен HUD-сценарий Play Mode, сохранены проверки этапов 1–2. Отсутствующие визуальные ссылки не участвуют в расчётах. Ручная оценка оформления/баланса и сборка остаются отдельными проверками.

**Добавлено:** Guides/UnitySetup, GitWorkflow, TestingGuide; отдельная настройка Unity во всех32 описаниях исходников. AGENTS дополнен качеством кода, workflow, безопасным fallback MCP, правилами автора Git и сохранения проверенных подэтапов.

**Исправления:** игровых изменений не требуется; уже существующая реализация этапа2 проверяется перед собственным локальным коммитом. Старые записи истории сохранены.

**Ограничения:** этот документационный коммит не отправляется автоматически. Крупные уже совместно реализованные изменения этапа2 сохраняются следующим единым проверенным коммитом, без создания искусственных промежуточных версий и переписывания истории. Проверки и ограничения остаются в Testing.

Связанные 21 описание исходников и 6 документов систем актуализированы вместе с README, Architecture, Testing и отчётом BattleStage2.

**Проверено заново:** 40/40 Edit Mode (job `ea6c5d5f6b76449283933d0e5c557aac`) и 17/17 Play Mode (job `10d4514cbdee4bf78a7408ddeed56654`), без проваленных и пропущенных тестов. ## 2026-10-11 — постоянные правила и начальная документация

**Добавлено:** корневой AGENTS.md с правилами сопровождения C#, систем и архитектуры; обязательными проверками/локальным коммитом; запретом push без явной команды. Созданы README, Architecture, Testing, документы 8 существующих систем и 32 отдельных C#-файлов (23 игровых,8 тестовых,1 служебный).

**Ограничения:** исходные незакоммиченные игровые изменения этапа 2 остаются вне текущего документационного коммита; документация описывает рабочую копию. Партия, level-up и дисковые сохранения отсутствуют. Внешняя сборка и настройки меню поведением здесь не проверялись. Push не выполняется.
