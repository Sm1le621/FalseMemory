# Переработка анимаций и движения — технический подэтап

## Статус2026-10-13

Полное задание владельца **In Progress**. В этом подэтапе исправляются физическое движение, связь темпа со скоростью и граница цикла. Рабочие рисунки из предыдущего коммита46556be сохраняются; новые пробные листы пока не назначены игровым объектам. Новые полноценные8-direction hero cycles, Hero/Skeleton Battle Idle6–10/Attack и новая Skeleton Walk-графика ещё не завершены. Нельзя считать задачу готовой только по числу кадров или успешным тестам.

## Что выявлено

- Hero Walk вправо: во многих прежних позах впереди одна и та же нога; рисунки различаются, но полноценная смена опорной ноги выражена плохо.
- Unity MCP подтвердил Dynamic Rigidbody обоих участников, gravity0/FreezeRotation, Interpolation=None/Discrete. EnemyAI вызывал MovePosition в Update; несколько render Updates могли не совпадать с физическим шагом.
- Сценовая скорость Hero4, Skeleton10 (значение по умолчанию в EnemyAI3). Частота шагов не учитывала реальное перемещение/остановку у стены.
- После смены частоты на12 ключ цикла был⅔с, но Unity сохраняла stopTime.75с. Новый runtime-тест обнаружил дополнительную задержку первого кадра; импортёр теперь явно задаёт startTime0/stopTime=frameCount/FPS.
- На Main Camera есть CameraFollow/UniversalAdditionalCameraData, orthographic size5, PixelPerfectCamera отсутствует. PPU/pivot и размеры рабочих Sprite не изменены; сама камера использовала зависящий от render FPS линейный коэффициент.

## Настройки и реальная последовательность

PlayerController остаётся прежним владельцем ввода и движения. Input System/WASD/стрелки читаются в Update; в FixedUpdate модуль скорости приближается к целевому, направление поворачивается сразу, Rigidbody.MovePosition выполняется только на шаге физики. Acceleration48/Deceleration80 world units/s², базовая скорость4 сохранена. Разгон до4≈.083с, торможение≈.05с, с дискретизацией fixedDeltaTime.02. При Inventory/отключении контроллера остановка немедленная. Диагонали нормализованы, атрибуты/gear продолжают давать прежние бонусы.

ActualMovementSpeed измеряет завершённый физический шаг с учётом стены. WalkSpeed=actual/reference4 (0…3) влияет только на существующее Walk-состояние; Idle не ускоряется. Все8 направлений сохраняют общую фазу при повороте. Текущие8 Sprite/направление: **12FPS,⅔с при скорости4**;12 — предварительный темп до художественной оценки. При замедлении частота снижается пропорционально. Замыкание петли исправлено без дополнительной задержки первого Sprite.

EnemyAI перенесён в FixedUpdate, разгон48; сценовая скорость**10→3**. Шаг ограничен расстоянием до цели, выход из прежнего detection trigger останавливает сразу. Радиус, collider shapes/offsets, EnemyAttack/BattleEncounter и правила встречи прежние. EnemySpriteAnimation продвигает walkClock по реальному расстоянию с reference3; hold.08 удерживает Walk между шагами, не двигая фазу неподвижных ног. Текущие4 ракурса×8 кадров,12FPS/⅔с при3. Отдельных8 скелетных ракурсов не добавлено.

В SampleScene обоим телам через MCP назначены **Interpolate и Continuous**; gravity0/FreezeRotation/scale/коллайдеры прежние. CameraFollow использует1−exp(−smoothSpeed×deltaTime), smoothSpeed5 сохранён. Time.fixedDeltaTime, FPS всей игры и масштаб карты не менялись.

BattleTransition при входе фиксирует физическую позицию и временно выключает simulation/interpolation участников, восстанавливая исходные режимы при возврате. Это необходимо для Interpolate: прежний render Transform мог отставать от physics pose и давать дрейф после победы/побега. Изначально simulated=false не включается автоматически. Повторное назначение физической позиции сбрасывает старую interpolation history. Health/MP/EXP и порядок ходов не копируются.

BattleScene не изменялась и заново не сохранялась. Прежние Battle Idle4/4FPS (цикл1с), Attack8/attackDuration.4с/contact.5 обоих участников остаются рабочим набором; урон по-прежнему один раз применяет BattleManager между Windup/Recover. World framesPerSecond12 в профиле не меняет длительность нормализованной боевой атаки. Полная новая художественная атака не заявляется.

## Обязательная ручная граница

Открыть SampleScene, включить Play и сфокусировать Game View:

1. Пройти WASD/стрелками во всех8 направлениях; несколько раз начать/остановиться и резко повернуть D→W→A. Проверить отзывчивость, отсутствие бокового заноса и сохранение взгляда. Оценить ходьбу/камеру при новом12FPS; один только более ровный темп не исправляет плохие рисунки ног.
2. Упереться в стену, открыть I во время движения: тело останавливается, ноги не продолжают полную ходьбу; закрытие окна возвращает управление.
3. Войти в радиус скелета: оценить более медленный подход3 вместо10, смену направления/шагов. Коснуться тела, проверить Attack/Defend/Fire/Heal, единственное изменение HP на удар, победу/возврат и отдельно Flee без немедленного нового боя.
4. Открыть сравнительные GIF8/10/12/15FPS в браузере. Оценить ритм и образец Right; Up с меняющим сторону оружием уже отклонён и не нуждается в принятии.

Дальнейшая художественная работа — исправление последовательности опорных/проходящих поз при неизменных деталях, затем остальные направления и новые Battle Idle/Attack героя/скелета. До этой ручной оценки общий подэтап5.3 классы не начинается. Наличие инструмента imagegen не гарантирует стабильную покадровую анатомию; текущие пробы это подтверждают.
